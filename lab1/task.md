# Задание 1: подготовка репозитория
• Создать Java проект с фреймворком Spring Boot версии 3.5.5 или выше;
• В качестве системы сборки проекта использовать Maven;
• Создать REST-контроллер с двумя разными GET эндпоинтами, выполняющими отличные друг от друга функции (например, один возвращает текст, а второй числа);
• B application.yml обязательно задать свойство spring.application.name, в значении указать номер своего студенческого билета;
• Опубликовать свой проект на GitHub;
• В качестве ответа на задание добавить в ЛМС ссылку на свой проект.
